# Example: custom orders

Adds an orders file (`data\commands\MyBarracks.xml`) with a second Hastatus button in the Roman barracks, on key `j`. Under **Controls → Content** it appears with the name set by the `commands` field of `mod.json`, in the game's language. Guide: [Mod keys](../../keys.md).

The `j` key and priority 20 are just examples. If you change the key, make sure it doesn't clash with other orders on the same bar.

It changes gameplay: in multiplayer everyone must have the mod.

To test it, copy this folder to `<game>\mods\`, enable it in the content manager and restart.
