# Example: unit with custom graphics

The **Simple Soldier**: a new unit with its own sprites, not reusing the Hastatus's. It's a cube soldier in 8 directions, with 6 animation sheets (idle, walk, attack, die, idle/combat transition and taunt), player color (tunic and crest change with the team) and shadow. It's recruited at the Republican Rome barracks (key `X`, 90 gold) and is weaker than the Hastatus, to tell them apart.

| File | What it is |
|---|---|
| `units\RSimpleSoldier\*.rle` | The sprites in the game's format (12 files, about 500 KB): one sheet per animation and its shadow. Generated, not hand-edited |
| `units\RSimpleSoldier\RSimpleSoldier.ent.xml` | The entity: which image is drawn on each layer and animation. Generated by `create-entity.js` |
| `data\classes\RSimpleSoldier.sc.xml` | The class (stats), with `entity="Units/RSimpleSoldier/RSimpleSoldier.ent.xml"` |
| `data\commands\SimpleSoldier.xml` | The order to recruit it at the barracks. Uses the Hastatus's portrait and button |
| `loc\spanish.loc.xml` | Name and button text in Spanish |

The sprites are drawn by `..\unit-graphics-generator\draw-soldier.js`, which isn't part of the mod (a mod doesn't accept `.js`). It draws the PNGs, calls `convert-sprite.js --player` and then `create-entity.js unit`. With your own drawings you skip the first step: [Custom graphics](../../graphics.md).

Careful: the script always writes inside this example's `units\RSimpleSoldier\` and overwrites whatever is there. If you just want to see the PNGs, `--png <folder>` leaves them there; but the `.rle` files and the `.ent.xml` are regenerated anyway. To leave the example untouched, work on a copy of the SDK:

```
node examples\unit-graphics-generator\draw-soldier.js
```

## How to test it

1. Validate (it should say OK): `node tools\validate-mod.js examples\unit-graphics-example --data <carpeta DATA sacada con extract-data.js> --game "<game folder>"`.
2. Copy this folder to `<game>\mods\`, enable it in the content manager (or in a profile) and restart.
3. Play Republican Rome in a skirmish, build a barracks and look for the new button ("Equip Simple Soldier"), or press `X` with the barracks selected.
4. Check:
   - If the game closes when loading the game: that's the typical failure of a badly loaded image. `Logs\imperivm\imperivm-mod.log` points to the image that failed.
   - Whether the tunic and crest come out in your player color and not magenta.
   - Whether it faces the way it walks. If it walks backwards or turns the wrong way, the game's 8-direction order is different (see "Direction order" in [Custom graphics](../../graphics.md)).
   - Whether the feet are at the unit's point and it has a shadow.
   - Whether it walks, attacks, dies and stays down, and whether it returns to idle after combat.
5. If something fails, remove the folder from `mods\` and go back to the profile with no mods.

It changes gameplay: in multiplayer every player must have the mod.
