# Example: Français

Adds French as a game language. It only translates the main menu and the options; the rest of the texts show in English. Guide: [Languages and texts](../../languages.md).

`mod.json` sets `"base": "spanish"` because the English pak ships no help, tips or menu images, and the Spanish one does. So those files appear in Spanish until you provide your own in `Local\french\`.

To test it:

1. Copy this folder to `<game>\mods\` and enable it in the content manager.
2. In **Options → Language**, pick **Français** and restart.
