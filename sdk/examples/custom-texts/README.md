# Example: custom texts

Changes a few menu texts without replacing the game's text file. Guide: [Languages and texts](../../languages.md).

For example, it changes "Single player" to "Un jugador" in Spanish and to "Giocatore singolo" in Italian. In English it says "Campaign and skirmish" instead of "Single player", just to show that English can be changed too.

To test it, copy this folder to `<game>\mods\`, enable it in the content manager and restart.
